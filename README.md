# 프로젝트 이름

  PDF 자료와 강의 녹음을 연결해, 페이지별 요약과 필기를 제공하는 학습 도구입니다.

  ## 프로젝트 소개

  강의 자료와 녹음 내용을 따로 확인하는 번거로움을 줄이고자 합니다.
  PDF를 페이지별로 설명하고, 녹음에서 나온 추가 설명을 관련 페이지에
  연결해 한 화면에서 복습할 수 있도록 만드는 것이 목표입니다.

  ## 개발 계획

  ### 1단계 — PDF 요약
  - [ ] PDF 파일 업로드
  - [ ] 파일별 전체 요약
  - [ ] 페이지별 요약 및 설명
  - [ ] 원문과 문장 위치 정보 저장

  ### 2단계 — 음성 요약
  - [ ] 음성 파일 업로드
  - [ ] 시간 정보가 포함된 대본 생성
  - [ ] 강의 핵심 내용 요약
  - [ ] 대본에서 해당 음성 구간 재생

  ### 3단계 — PDF와 음성 연결
  - [ ] 음성 대본과 PDF 내용을 비교해 관련 페이지 연결
  - [ ] 페이지별로 녹음 기반 필기 표시
  - [ ] 문장·그림 단위 하이라이트와 메모
  - [ ] 필기 수정 및 연결 위치 변경
  - [ ] 필기가 포함된 PDF 내보내기

  ## 목표 사용 흐름

  PDF와 음성 파일 업로드
  → 자료 분석 및 요약
  → 녹음 설명과 PDF 위치 연결
  → 필기 확인·수정
  → 복습 및 PDF 내보내기

  ## 현재 상태

  기획 및 기술 검토 단계입니다.
  PDF 요약 기능부터 순차적으로 구현할 예정입니다.
